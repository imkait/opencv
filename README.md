# OpenCV 視覺實驗室

給高中生的 OpenCV 入門教學網站，供老師投影講解，也供學生課後複習。學生使用 Windows、VS Code、AI Agent、uv、Python 與攝影機，在自己的電腦上完成實作；網站本身不存取攝影機，也不記錄進度。

## 教材內容

1. 電腦視覺與 OpenCV 的基本概念。
2. Windows 開發環境與 uv 專案準備。
3. 四個附完整註解程式碼的基礎實作：讀取鏡頭、灰階與其他效果、鏡像翻轉、儲存畫面。
4. 四個攝影機核心實作：影像分類、人臉偵測、表情分類、人臉比對。
5. 七個延伸挑戰：影像分類兩項、人臉偵測三項、表情分類兩項。
6. 基礎程式碼、Agent 提示詞、驗收方法、排錯思路與官方資料來源。

教材以 [OpenCV 官方文件](https://docs.opencv.org/)與 [OpenCV Zoo](https://github.com/opencv/opencv_zoo) 為基礎。模型檔案及授權資訊請以對應的官方範例目錄為準。

## 本機預覽

直接以瀏覽器開啟 `index.html` 即可閱讀。網站使用原生 HTML、CSS、JavaScript，不需要安裝套件或執行建置步驟。所有實作示意圖都在 `assets/`，離線時仍可閱讀教材；外部字型若無法載入會使用系統字型。

## 檔案

- `index.html`：教材內容與官方連結。
- `styles.css`：響應式版面及投影模式。
- `app.js`：程式碼與提示詞複製、投影模式切換。
- `assets/`：三張原創的概念示意圖與楠梓高中校徽；實際模型效果請參照各課連結的官方範例。頁首優先載入教師提供的[楠梓高中官方圖片](https://www.nths.kh.edu.tw/images/nths_s.png)，無法連線時使用本機既有的同校校徽素材。

## 內容維護

修改教材時，請確認 OpenCV Zoo 的模型檔名、來源、授權與安裝方式是否仍與官方資料一致。攝影機版的影像分類、人臉比對與各延伸作品是依官方範例設計的課堂任務，並非原始範例逐字重現。
