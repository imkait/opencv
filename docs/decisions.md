## 2026-10-25：精簡延伸作品清單

**背景**：教師要求移除 A03、C03，以及人臉比對的 D01–D03。

**決定**：保留七個延伸作品：影像分類兩項、人臉偵測三項、表情分類兩項；人臉比對僅保留核心實作。此決定更新了 2026-10-23 紀錄中的十二項數量，原紀錄保留作為歷史。

**影響**：教材不再宣稱每個核心實作都有三個延伸作品；人臉比對課程結束後直接進入複習。

**狀態**：已採用

## 2026-10-25：基礎練習提供完整程式碼

**背景**：教師希望學生在進入模型應用前，先親自操作攝影機讀取、灰階處理、鏡像翻轉與影格存檔。

**決定**：四個不使用模型的基礎實作提供可獨立執行、附詳細註解的 Python 程式碼與檔名。模型核心實作及其延伸作品仍以 Agent 提示詞為主。

**影響**：學生可先修改簡單參數與觀察影像變化，再進入 AI Agent 生成程式的課程。

**狀態**：已採用

## 2026-10-23：教學網站與學生實作分開

**背景**：網站供老師投影講解與學生課後複習；學生使用 Windows、VS Code、AI Agent、uv、Python 和攝影機完成實作，不需記錄完成度。

**決定**：網站使用原生 HTML／CSS／JavaScript 製作靜態教材，不直接啟用瀏覽器攝影機，也不保存學生資料。四個核心主題由老師帶做，十二個延伸作品由學生自行探索；以提示詞、驗收條件與官方來源為主要教材。

**考慮過的替代方案**：
- 網站內執行攝影機辨識：與學生既定的本機 Python 學習環境不符。
- 為模型應用提供完整範例程式碼：不符合以 Agent 生成、學生觀察與驗收為主的教學方式；四個基礎練習另依 2026-10-25 決策提供程式碼。

**影響**：網站可以直接開啟並於 OneDrive 同步；模型與 Python 程式需由學生依教材在本機準備。官方模型版本與來源連結應定期核對。

**狀態**：已採用
